# ATR_MS2 v7fix-200

`ATR_MS2_V08021.xlsm`（v6 / 最新保存）を土台に、`ATR_MS2_V08021_fix_v7.xlsm` の
修正をすべて取り込み、**200銘柄対応**にしたものです。

| ファイル | 用途 |
|---|---|
| `ATR_MS2_V08021_v7fix_200.xlsm` | 完成ブック。これを開いて使う |
| `MS2_Core_v7fix_200.bas` | 同じコードの単体ファイル。差し替え用の保険 |

---

## 1. 何を直したか

### fix_v7 が抱えていた「そのままでは動かない」2つの欠陥

- **構文エラー8箇所**
  文字列リテラルの行末に余分な `"` が付いており、モジュール全体がコンパイル不能でした。
  `MS2_Install_Settings` / `MS2_Fill_Trade_Names` / `MS2_Show_Log`（2箇所）/
  `MS2_Fix_TRADE_Header`（4箇所）を修正。
- **文字コードの不一致**
  VBAプロジェクトの codepage は 932（Shift-JIS）なのに、モジュール本文が UTF-8 で
  格納されていました。日本語版 Excel では VBE が文字化けし、`"操作パネル_MS2"` などの
  日本語リテラルも壊れて実行時エラーになります。CP932 で格納し直しました。

### 200銘柄対応

対応銘柄数を1箇所で管理できるようにし、関連する範囲をすべて連動させました。

```vb
Private Const STOCK_MAX    As Long = 200                        ' 扱う銘柄数
Private Const STOCK_LAST   As Long = STOCK_MAX + 1              ' StockList_MS2 の最終行 = 201
Private Const DATA_LAST    As Long = DATA_FIRST + STOCK_MAX - 1 ' DATA_MS2 の最終行 = 202
Private Const HIST_LAST    As Long = STOCK_LAST                 ' ATRHIST_MS2 の参照上限 = 201
Private Const DATA_CLEAN   As Long = 400                        ' 旧レイアウトの残骸を掃除する下限行
Private Const HIST_CLEAN   As Long = 400
```

- StockList 参照の固定 `$2:$400` を `STOCK_LAST` 連動に変更
- 旧350行レイアウトの残骸（DATA_MS2 の203〜352行）を 400行目まで掃除するように拡張
- TRADE_MS2 見出しの「(100株)」表記を「(円)」に統一（実体は操作パネル H13 での換算）
- `MS2_Version`（バージョン確認）を追加。操作パネルにもボタンを追加

### fix_v7 由来の修正（v6 → v7）

| ID | 内容 |
|---|---|
| A-1 | ATRHIST が当日更新のときだけ実測ATRを採用（操作パネル H17 で判定） |
| A-2 | 前営業日以前の建玉を当日値で判定せず `EXPIRED` で閉じる |
| A-4 | 現在値が 0／文字列の行を `N()` ガードで判定対象から除外 |
| B-2 | 銘柄反映は StockList の実件数ぶんだけ書き、余りは消す |
| B-4 | シグナル追記時に TRADE_MS2 の N/O/P/Q 補助列も同時に張る |
| B-5 | RANK_MS2 の損益を売買単位（H13）で円換算し TRADE と単位を統一 |
| C-1 | 予約が入らなかったときに「開始しました」と言わない |
| C-2 | 列全体参照を有限範囲に。最終更新の書き込みは足の切替時のみ |
| C-4 | 足の長さを操作パネル H9 から読む（従来は定数5で固定） |
| C-5 | 同じ日に二重保存しない |
| C-6 | RANK_MS2 を月次損益の降順に並べ替え。PF/RR は数値のまま（999=∞） |
| C-8 | エラー時に成功メッセージを出さない |
| C-9 | 実銘柄数だけをループ |
| ― | Y列（時間帯）の `NOW()` を操作パネル H15 の1セルに集約。抜けていた「前場」を追加 |
| ― | TRADE_MS2 に U列（同日損益・内部）を追加し、MINIFS を使わず最大損失を算出 |

## 2. 使い方（200銘柄にする手順）

1. `ATR_MS2_V08021_v7fix_200.xlsm` を開く（マクロを有効化）。
2. 操作パネルの **「バージョン確認」** を押し、`MS2_Core v7fix-200` と
   `対応銘柄数: 200 銘柄` が出ることを確認する。
   → 出ない、またはボタンが無い場合は下の「3. うまくいかないとき」へ。
3. `StockList_MS2` の **A102〜A201** に追加の銘柄コードを入力する。
4. `B101` を **B102〜B201** にコピーする（銘柄名を引く RssMarket 式）。
5. 操作パネルのボタンを **この順で** 実行する。

   1. 銘柄反映_MS2
   2. RSS式セット_MS2
   3. 判定式セット_MS2
   4. 前日値反映_MS2

6. 取引時間中に `ATR収集_開始` → 以降は `全自動_MS2`。

> E〜L列は銘柄コードを直書きした RssMarket 式なので、銘柄を入れ替えたら
> 必ず 1〜4 を通してください。単独では追従しません。

## 3. うまくいかないとき（コードの差し替え）

Excel が古いコンパイル済みコードを掴んだままの場合、
「バージョン確認」ボタンが無い／`マクロが見つかりません` になります。
その場合は次の手順で確実に入れ替わります。

1. `Alt` + `F11` で VBE を開く。
2. 左のツリーで `標準モジュール` → `MS2_Core` を右クリック →
   **「MS2_Core の解放」**（保存するか聞かれたら「いいえ」）。
3. メニューの `ファイル` → **「ファイルのインポート」** で
   `MS2_Core_v7fix_200.bas` を選ぶ。
4. `デバッグ` → **「VBAProject のコンパイル」** でエラーが出ないことを確認。
5. Excel に戻り、操作パネルの `TRADE見出し修復` を一度実行してから上書き保存。

## 4. 注意点

- **RANK_MS2 の集計対象が変わります。** v7 以降は「同日決済」のみを成績に含めます。
  現在 TRADE_MS2 にある91件のうち同日決済は22件、日跨ぎが69件なので、
  集計母数が 91 → 22 に減ります。デイトレ前提としては正しい挙動です。
- 日跨ぎの建玉は `結果 = EXPIRED` で閉じられ、損益0として集計から外れます。
  引け（15:30〜15:45）に `結果判定_MS2` を必ず1回実行してください。
- `ThisWorkbook` に `Workbook_Activate` はありません。ブックを閉じる操作を
  キャンセルした直後は `gShuttingDown` が立ったままになることがあります。
  その場合は `★タイマー全解除` を一度押してから `ATR収集_開始` してください。
