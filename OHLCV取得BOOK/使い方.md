# OHLCV 時刻別 取得BOOK  v1.0

## これは何か
決められた時刻の OHLCV を **確実に残すためだけ** のBOOK。
計算も抽出もしない。取って保存するだけ。

## 取得する時刻（14本）
9:00 / 9:10 / 9:20 / 9:45 / 10:00 / 10:15 / 10:30 /
11:30 / 12:30 / 13:30 / 14:30 / 15:00 / 15:20 / 15:30

→ 設定シートのA列を書き換えれば自由に増減できる。

## 取り込み手順（1回だけ）
1. 新しいブックを作り、**マクロ有効ブック(.xlsm)** で保存する
   例）`OHLCV取得BOOK.xlsm`
2. `Alt + F11` でVBEを開く
3. メニュー「ファイル」→「ファイルのインポート」→ `Mod_OHLCV取得.bas` を選ぶ
4. 左のツリーで `ThisWorkbook` をダブルクリック → `ThisWorkbook.txt` の中身を貼り付け
5. VBEを閉じて、マクロ `初期設定` を実行（Alt+F8）
6. 上書き保存

## 毎日の使い方
| やること | 操作 |
|---|---|
| 銘柄を足す | 銘柄シートA列にコードを打つ → 「銘柄反映」ボタン |
| 銘柄を消す | その行を丸ごと削除 → 「銘柄反映」ボタン |
| 一時的に外す | 銘柄シートC列に `×` を入れる → 「銘柄反映」ボタン |
| 他BOOKから銘柄をもらう | 「銘柄取込」ボタン → **ファイルを選ぶだけ**。コード列は自動で探します |
| 始める | 「監視開始」ボタン（BOOKを開けば自動で始まる） |
| 止める | 「監視停止」ボタン |
| ブザーを止める | 「ブザー停止」ボタン |

## シートの中身
| シート | 中身 |
|---|---|
| 銘柄 | 銘柄コードの台帳。ここだけ触ればよい |
| 取得 | RSSの実況板。I1にRSSの状態が出る |
| 記録 | 取得した実データ（日付/時刻区分/コード/OHLCV） |
| ログ | いつ何をしたか、何が起きたか |
| 設定 | 取得時刻・保存先・ブザー設定・ボタン |

## PCトラブル対策（ここが本題）
1回取るたびに **3か所** に書く。
1. 記録シートに追記
2. **CSVファイルに追記** ← 本命。1行ずつ書くので途中で落ちてもそこまでは残る
   `OHLCV_20260907.csv`（保存フォルダは設定シートD1）
3. ブックを自動保存

ログも `OHLCV_LOG_202609.txt` にテキストで二重に残す。
ブックが壊れてもCSVとログは無事。

## RSS切断の警告
30秒ごとに見張って、次のどちらかなら「切断」と判断する。
- 先頭20銘柄の現在値がひとつも取れない
- ザラバ中に出来高が5分間まったく動かない（＝RSSが固まった）

切断したら
- 取得シート I1 が **真っ赤に「★RSS切断★」**
- **ブザーが30秒おきに10分間鳴る**（設定シートの「ブザー間隔秒」「ブザー継続分」で変更可）
- ログに「重大」で記録

回復したら自動でブザーが止まり、ログに「復旧」と入る。
9:00〜15:35 の平日だけ鳴る（夜中に鳴らないため）。

## 他のBOOKとぶつからない工夫
- 取得は「時刻ちょうど」ではなく **5秒後**に動かす（設定で変更可）
- CSV書き込みは **ロックファイル**で排他。使用中なら見送ってログに残す
- 取れなかったら **30秒後に自動で再挑戦**（30分まで粘る）
- 自動処理中は **MsgBoxを一切出さない**（ダイアログで止まらないため）
- タイマーは常に1本だけ。二重起動しない

## 銘柄取込（ボリンジャー送信BOOKなど）
「銘柄取込」ボタン → ファイルを選ぶだけ。
- 全シートのA〜L列を調べて、**4桁コードが一番多い列**を自動で見つける
- 「シート○○のB列、287件でよいか？」と確認が出る → はい
- 重複コードは自動で捨てる
- そのまま「銘柄反映」まで一気にやるか聞いてきます

`7203` のような数字コードも `130A` のような新形式コードも拾います。

## 注意
- 楽天RSS（マーケットスピードII RSS）が起動している必要がある
- 記録シートは 1銘柄×14回/日。500銘柄なら年間175万行になるので、
  半年に一度は記録シートを別ファイルへ退避すること（CSVは日別なので問題なし）
