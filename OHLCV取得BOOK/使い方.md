# OHLCV 時刻別 取得BOOK  v1.0

## これは何か
決められた時刻の OHLCV を **確実に残すためだけ** のBOOK。
計算も抽出もしない。取って保存するだけ。

## 取得する時刻（14本）
9:00 / 9:10 / 9:20 / 9:45 / 10:00 / 10:15 / 10:30 /
11:30 / 12:30 / 13:30 / 14:30 / 15:00 / 15:20 / 15:30

→ 設定シートのA列を書き換えれば自由に増減できる。

**引けの2本は1分ずらして取りに行きます。**
| 表示 | 実際に取る時刻 | 理由 |
|---|---|---|
| 11:30 | **11:31** | 前引けが確定してから |
| 15:30 | **15:31** | 大引けが確定してから |

終値列には**確定した終値（現在値）**が入ります。
シート名も列見出しも `11:30` `15:30` のままです。

| 設定シート | 意味 |
|---|---|
| A列 取得時刻(表示) | シート名・列見出しに使う時刻 |
| B列 実取得時刻 | 実際に取りに行く時刻。**空ならA列と同じ**。11:30→11:31、15:30→15:31 |

他の時刻も遅らせたければ、B列に時刻を入れるだけです。

## ★差し替えるときの注意（これを守らないと動きません）
新しい `.bas` を入れる前に、**必ず古いモジュールを削除**してください。
削除しないと `Mod_OHLCV取得1` という2つ目のモジュールができて、
Alt+F8 で**古いほうの初期設定が動いてしまいます**（時刻シートが増えない原因）。

1. `Alt+F11` でVBEを開く
2. 左のツリーに `Mod_OHLCV取得` が **1つだけ**か確認する
   （`Mod_OHLCV取得1` があれば、それも削除する）
3. 右クリック → **「Mod_OHLCV取得 の解放」** → 「エクスポートしますか」は **いいえ**
4. ファイル → ファイルのインポート → 新しい `.bas`
5. `Alt+F8` → **初期設定**

初期設定が終わると **「このBOOKのシート合計 : 24 枚」** と出ます。
24枚でなければ、出てきたメッセージの中身を教えてください。

## 取り込み手順（1回だけ）
1. 新しいブックを作り、**マクロ有効ブック(.xlsm)** で保存する
   例）`OHLCV取得BOOK.xlsm`
2. `Alt + F11` でVBEを開く
3. メニュー「ファイル」→「ファイルのインポート」→ `Mod_OHLCV取得.bas` を選ぶ
4. 左のツリーで `ThisWorkbook` をダブルクリック → `ThisWorkbook.txt` の中身を貼り付け
5. VBEを閉じて、マクロ `初期設定` を実行（Alt+F8）
6. 上書き保存

## シートの中身（全24枚 ＝ 作業5枚 ＋ 集積19枚）
| シート | 中身 |
|---|---|
| 銘柄 | 銘柄コードの台帳。ここだけ触ればよい |
| 取得 | RSSの実況板。I1にRSSの状態が出る |
| 記録 | 取得した実データが下へ積み上がる（大元） |
| ログ | いつ何をしたか、何が起きたか |

| 0900・0910・0920・0945・1000・1015・1030・1130・1230・1330・1430・1500・1520・1530（14枚） | 時刻ごとの集積表。列＝日付（5列で1日） |

## 集積19シート（このBOOKだけ見れば全部わかる形）

### ① OHLCV 5シート（始値／高値／安値／終値／出来高）＝ 日足
**時刻はありません。1日1列**。その日の大引け（15:30）のOHLCVが入ります。

```
      A      B         C       D       E    ...
1                    09/07   09/07   09/07      ← 日付
2                    09:00   09:10   09:20      ← 時刻
3   コード  銘柄名
4   7203   トヨタ     2850    2855    2861
5   6758   ソニー     3120    3118    3125
```
```
      A       B          C          D          E
1                     26/09/07   26/09/04   26/09/03   ← 左が新しい
2                       月         金         木        ← 曜日
3   コード   銘柄名
4   5706    三井金属    26,380     25,745     25,900
```
1日 **1列**。上限は約 **16,000営業日**。

### ② 時刻別14シート（`0900` `0910` … `1530`）
「9:00時点の値が日々どう動いたか」を追うときに見る。

```
      A      B         C      D      E      F      G       H      I ...
1                    09/05  09/05  09/05  09/05  09/05   09/08 ...   ← 日付
2                    始値   高値   安値   終値   出来高   始値  ...   ← 項目
3   コード  銘柄名
4   7203   トヨタ    2840   2860   2835   2850   45000   ...
5   6758   ソニー    3110   3130   3105   3120   28000   ...
```
1日 **5列**。上限は約 **3,270営業日（13年）**。時刻ごとのOHLCVはこちらで見ます。

### 共通のしくみ
- 銘柄は**コードで照合**するので、行がずれても正しい場所に入る
- 新しい銘柄は自動で下に足される。消した銘柄の行は過去データを守るため残る
- C4で**ウィンドウ枠固定**済み（左に銘柄、上に日付が常に見える）
- 列が増えすぎるとログに警告が出る

### 作り直し
19シートがおかしくなったら「**集積作り直し**」ボタン。
記録シートから全部並べ直します（記録シートとCSVは触りません）。

つまり —
**記録シート＋CSVが正（絶対に守る） → 集積19シートは見るための表（いつでも作り直せる）**

## PCトラブル対策（ここが本題）
1回取るたびに **4か所** に書く。
1. 記録シートに追記
2. **CSVファイルに追記** ← 本命。1行ずつ書くので途中で落ちてもそこまでは残る
   `OHLCV_20260907.csv`（保存フォルダは設定シートD列）
3. 集積19シートの右端に列を追加（値別5枚に1列ずつ／時刻別1枚に5列）
4. ブックを自動保存

ログも `OHLCV_LOG_202609.txt` にテキストで二重に残す。
ブックが壊れてもCSVとログは無事。

## RSS切断の警告
30秒ごとに見張って、次のどちらかなら「切断」と判断する。
- 先頭20銘柄の現在値がひとつも取れない
- ザラバ中に出来高が5分間まったく動かない（＝RSSが固まった）

切断したら
- 取得シート I1 が **真っ赤に「★RSS切断★」**
- **ブザーが30秒おきに10分間鳴る**（設定シートの「ブザー間隔秒」「ブザー継続分」で変更可）
- ログに「重大」で記録

回復したら自動でブザーが止まり、ログに「復旧」と入る。
9:00〜15:35 の平日だけ鳴る（夜中に鳴らないため）。

## 他のBOOKとぶつからない工夫
- 取得は「時刻ちょうど」ではなく **5秒後**に動かす（設定で変更可）
- CSV書き込みは **ロックファイル**で排他。使用中なら見送ってログに残す
- 取れなかったら **30秒後に自動で再挑戦**（30分まで粘る）
- 自動処理中は **MsgBoxを一切出さない**（ダイアログで止まらないため）
- タイマーは常に1本だけ。二重起動しない

## 銘柄取込（ボリンジャー送信BOOKなど）
「銘柄取込」ボタン → ファイルを選ぶだけ。
- 全シートのA〜L列を調べて、**4桁コードが一番多い列**を自動で見つける
- **候補が複数ある場合は一覧で出る**ので番号を選ぶ（19シートのBOOKでもOK）
  例）`1 : 終値 / A列 / 287件`  `2 : 銘柄管理 / B列 / 287件`
- 重複コードは自動で捨てる
- そのまま「銘柄反映」まで一気にやるか聞いてきます

`7203` のような数字コードも `130A` のような新形式コードも拾います。

## 過去データ取込（既存BOOKのOHLCV履歴を移す）
「**過去データ取込**」ボタン → 売買BOOKなどを選ぶだけ。

- 相手BOOKの **始値／高値／安値／終値／出来高** 5シートを読む
- 日付の見出し行・データ開始行・日付列は**自動で見つける**
- 銘柄は**コードで照合**するので行がずれていても正しく入る
- 記録シートに「**15:30 の記録**」として書き足す（取得時刻列は `(履歴)`）
- 今の記録シートは消さない。足すだけ
- そのあと「集積作り直し」まで一気にやるか聞いてきます

終値が 0 や空の日は「その日はデータ無し」として飛ばします。

**元BOOKは「計算を止めた状態」で開きます。**
RSS数式がいっぱい入ったBOOKでも固まりません。
それでも開くのに1〜2分かかることがあります。画面下に進み具合が出るので待ってください。

## 他BOOKとの同時刻対策（TICK取得など）
- 取得は時刻ちょうどでなく **+5秒後**（設定シート「取得遅延秒」）
- 取れなければ **30秒ごとに30分粘る**
- 他BOOKが「計算を手動」にしていても、取得直前に自動へ戻して正しい値を読む
- 60秒以上遅れたらログに警告が出る（競合が起きているサイン）
- **保存は1日2回だけ**（11:35 / 15:45）。TICK取得中の重い保存を避ける

### もしもの保険：CSV復元
「**CSV復元**」ボタン → `OHLCV_20260907.csv` を選ぶだけ。
記録シートに戻します。**重複する行は自動で除きます**ので、何度押しても安全です。
そのあと「集積作り直し」まで続けられます。

## 注意
- 楽天RSS（マーケットスピードII RSS）が起動している必要がある
- 記録シートは 1銘柄×14回/日。500銘柄なら年間175万行になるので、
  半年に一度は記録シートを別ファイルへ退避すること（CSVは日別なので問題なし）
