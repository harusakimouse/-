# ボリンジャーバンド 買い候補スクリーニング＆バックテスト

既存の楽天RSS株価管理システム（`打ち出のこづち_0615MOD整理 改善 .xlsm`）に、
ボリンジャーバンド（**SMA20・±1σ/±2σ**）による買い候補抽出とバックテストを追加した版が
**`打ち出のこづち_ボリンジャー版.xlsm`** です。

## 重要
- 既存シート（銘柄管理・分析・終値/高値/安値/出来高・VBAマクロ・楽天RSS連携・図形・条件付き書式など）は
  **一切変更していません**。ZIP/XMLレベルで新しいシートだけを追加しています。
- データは既存の `終値・高値・安値・出来高` シート（楽天RSS取得の60日履歴）をそのまま参照するため、
  **二重入力は不要**です。いつも通り更新→F9で全自動計算されます。

## 追加した6シート
| シート | 内容 |
|---|---|
| **BB使い方** | 使い方と戦略サマリー表（スクイーズブレイク/トレンドフォロー/ダブルトップ・ボトム/ダイバージェンス、利確・損切り原則） |
| **BB設定** | パラメータ（青字セルで変更可）＋シグナル凡例 |
| **BBスクリーニング** | 全銘柄（400行）を1行1銘柄で自動計算。SMA20・±1σ/±2σ・%B・帯幅・スクイーズ・RSI・MFI・ダイバージェンス・二番底・戦略シグナル・スコア・利確/損切り/RR |
| **BB買い候補TOP** | スコア上位30銘柄を自動抽出 |
| **BBバックテスト** | 銘柄コードを入れると過去検証（+2σ突破で買い→+1σ割れで手仕舞い、勝率・損益） |
| **BB_帯幅** | スクイーズ判定用の帯幅履歴（自動計算・非表示） |
| **BB_スイング** | 二番底/天井の厳密スイング検出用（自動計算・非表示） |

## 計算仕様（要点）
- 移動平均は **SMA（単純移動平均）** 、期間20日（`AVERAGE(終値!E:X)`）。
- σは母標準偏差 `STDEVP`。±2σ=SMA±2σ、±1σ=SMA±1σ。
- **スクイーズ**＝帯幅（=4σ/SMA）が過去40日の最小付近（`BB設定`の許容係数以下）。
- **RSI(14)/MFI(14)** はSUMPRODUCTで算出（MFIは (高値+安値+終値)/3 × 出来高）。
- **ダイバージェンス**＝10日前と比較し、価格とRSIが逆行したとき検出。
- **ダブルトップ/ボトム**＝フラクタル(前後2本より安値/高値が突出)で**厳密にスイング(ピボット)検出**。
  直近2つのスイング安値(高値)が同水準(許容%内)で、間にネックライン(戻り%以上)があり、
  2番目が現値割れせず反発していればW/M型。ネックライン上抜け/下抜け、または
  「1回目バンド外→2回目バンド内」で「確」判定。
- **利確**＝+1σを実体割れ／**損切り**＝ミドル(SMA)割れ（価格がミドル未満なら直近5日安値）。
