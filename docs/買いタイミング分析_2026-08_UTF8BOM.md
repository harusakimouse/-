# 日本株 売買タイミング（価格）分析レポート

**分析日**: 2026/08/15
**対象ブック**: 総合売買抽出BOOK V1 (V8.17) ─ 現在稼働中のブック
**対象データ**: 同ブックの 始値/高値/安値/終値/出来高 シート
**サンプル**: 300銘柄 × 250営業日（2025/07/31 〜 2026/08/14）= 延べ 50,671 銘柄日
**シグナル定義**: Mod_買抽出v13 のスコアロジックをPythonで再現（スコア11以上 = 6,975件、16以上 = 589件）

## 0. 結論（先に）

**指値 ＝ 当日終値 − 0.75 × ATR(14)。3営業日有効。刺さらなければ見送り。**

| | 現行（翌日寄付で成行） | 推奨（終値−0.75ATR 指値） |
|---|---|---|
| 平均損益 | +0.179R | **+0.413R** |
| 勝率 | 46.2% | **53.1%** |
| 年間取引数 | 494 | 477 |
| 年間合計 | +88R | **+197R** |
| 1R=4万円 換算 | +353万円 | **+787万円** |

同じ銘柄・同じ決済ルールで、**入る値段を変えるだけ**で期待値が 2.3倍 になる。

## 1. 「買うと下がる」は気のせいではない（が、原因は思っているものと違う）

v13シグナルが出た翌日、寄付で買った場合の値動き：

| | 平均 | P10 | P25 | 中央 | P75 | P90 |
|---|---|---|---|---|---|---|
| 翌日ギャップ（翌日始値/当日終値） | +0.38% | -1.84% | -0.69% | +0.05% | +0.94% | +2.41% |
| **翌日安値/翌日始値（買った日の含み損）** | **-2.19%** | -4.99% | -2.67% | **-1.33%** | -0.58% | -0.19% |
| 翌日高値/翌日始値 | +2.30% | +0.10% | +0.49% | +1.23% | +2.64% | +5.26% |
| 翌日終値/翌日始値 | +0.00% | -3.39% | -1.40% | -0.02% | +1.26% | +3.12% |

- 寄付で買って**当日一度でも含み損になる確率：95.8%**
- -1%以上下げる確率：60.2%／-2%以上：35.7%

高精度シグナル（スコア16以上）はさらに荒く、中央 -2.14%、-2%超えが 52.3%。
**スコアが高い銘柄ほど、買った直後の下げは大きい。** 高スコア＝出来高急増・大陽線・高ボラだから当然の結果。

ただし重要なのは比較対象で、**母集団（全銘柄・全日）でも 95.2%、中央 -1.21% 下げている**。
つまり「買った瞬間に含み損」はシグナルの欠陥ではなく、**日中の値幅がある以上、寄付が当日の最安値になることはまずない**という当たり前の事実。
問題は「下がること」ではなく「**下がる分を最初から値段に織り込んでいない**」こと。

## 2. どこまで下がるか ─ ATRで測ると驚くほど安定している

翌日の安値が、当日終値から何ATR下まで来るか（k = (当日終値 − 翌日安値) ÷ ATR14）：

| 分位 | k | 意味 |
|---|---|---|
| P10 | -0.25 | 1割の日は終値より上でしか買えない |
| P25 | +0.07 | |
| **P50** | **+0.46** | **半分の日は 0.46ATR 下まで落ちる** |
| P75 | +0.91 | |
| P90 | +1.43 | |

平均 +0.51ATR。終値割れ（k>0）は 78.2%。

**この k は、条件を変えてもほとんど動かない：**

| 条件 | 中央 k |
|---|---|
| 対前日比 0〜2% | +0.41 |
| 対前日比 +9%以上（急騰直後） | +0.60 |
| 出来高倍率 1.2倍未満 | +0.41 |
| 出来高倍率 3.5倍以上 | +0.95 |
| ATR率 2%未満（低ボラ） | +0.42 |
| ATR率 6%以上（高ボラ） | +0.55 |
| 市場全体が -0.5%以下の日 | +0.46 |
| 市場全体が +0.5%以上の日 | +0.45 |

**%で見ると激変する要因が、ATRで割ると消える。** これが本レポートの中心的発見。

参考：%で見た場合の翌日含み損（中央値）
- ATR率 1.5%未満 → -0.51% ／ ATR率 8%超 → -5.20%（**10倍の差**）
- 対前日比 0〜2% → -0.96% ／ +9%以上 → -3.92%
- 出来高倍率 0.8〜1.2倍 → -1.15% ／ 3.5倍以上 → -4.29%
- 25日EMA乖離 3%以内 → -0.85% ／ 10%超 → -2.39%
- 翌日ギャップ +5%以上で寄った場合 → 寄付からさらに -4.16%

→ 「**急騰銘柄に飛びつくと痛い**」は事実。ただしその正体は**ボラティリティが高いこと**であって、
　 ATRに比例した指値を置けば自動的に補正される。銘柄を選り好みする必要はない（§5で検証）。

### 支持線としてはどこが機能するか

| 水準 | 終値比 | 翌日安値が到達する率 |
|---|---|---|
| 当日終値 | ±0% | 80.2% |
| 終値 −0.5ATR | -1.50% | 47.3% |
| 当日安値 | -2.26% | 31.7% |
| 5日EMA | -2.25% | 34.2% |
| 5日VWAP | -2.53% | 32.6% |
| 終値 −1.0ATR | -3.01% | 21.2% |
| 25日EMA / 25日VWAP | -6.26% | 8.8% / 12.1% |
| 終値 −2.0ATR | -6.02% | 3.3% |

5日EMA・5日VWAP・当日安値は**ほぼ同じ水準（終値−2.3%前後）に集まる**。
25日EMA/VWAPまで待つと年に数回しか買えない（到達率9〜12%）。実用的な押し目待ちの射程は **−0.5ATR 〜 −1.25ATR**。

## 3. 指値をいくら下に置くか ─ 単体検証

シグナル日ごとに指値を置いた場合。決済は現行ルール（損切2ATR[3〜10%に制限]・利確2R・10営業日で時間決済）。

**スコア11以上（n=7,026）**

| エントリー | 約定率 | 平均約定価 | 平均R | 勝率 |
|---|---|---|---|---|
| 翌日寄付で成行 | 100% | ±0.00% | +0.241 | 50.4% |
| 指値 1.0%下 | 56.0% | -1.59% | +0.226 | 49.5% |
| 指値 3.0%下 | 25.5% | -3.49% | +0.244 | 47.8% |
| 指値 ATR×0.50下 | 47.0% | -2.26% | +0.250 | 50.8% |
| **指値 ATR×1.00下** | 20.8% | -4.08% | **+0.314** | 52.1% |
| 指値 ATR×1.50下 | 8.5% | -6.08% | +0.388 | 54.7% |
| 指値 ATR×2.00下 | 3.3% | -8.26% | +0.523 | 58.1% |

2点わかる：

1. **%指定よりATR指定が明確に優れる。** 同じ約定率25%前後で比べると、3%下の指値が +0.244R に対し
   ATR×1.0下は +0.314R。ボラティリティの違いを無視した%固定は、低ボラ銘柄では深すぎ、高ボラ銘柄では浅すぎる。
2. **深くするほど1回あたりの質は上がるが、約定率が落ちる。** 1銘柄だけを追うなら成行が有利に見える。

しかし実運用は「毎日出る候補から数銘柄を選ぶ」ので、この見方は誤り（→ §4）。

## 4. 運用シミュレーション ─ 毎日スコア上位10候補から最大2銘柄

現実の使い方（候補が複数あり、資金枠は限られる）で検証。

| 戦略 | 年間取引 | 平均R | 勝率 | 年間合計R | 平均含み損 |
|---|---|---|---|---|---|
| 翌日寄付で成行（現行） | 494 | +0.179 | 46.2% | +88.2 | -6.46% |
| 指値 −0.25ATR（当日限り） | 489 | +0.186 | 47.3% | +91.1 | -6.57% |
| 指値 −0.50ATR（当日限り） | 477 | +0.288 | 50.2% | +137.1 | -6.21% |
| **指値 −0.75ATR（当日限り）** | 428 | **+0.416** | 54.0% | +178.2 | -5.76% |
| 指値 −1.00ATR（当日限り） | 348 | +0.368 | 51.1% | +128.1 | -6.41% |
| 指値 −1.50ATR（当日限り） | 217 | +0.512 | 58.3% | +111.3 | -6.05% |
| 指値 −0.50ATR（3日有効） | 486 | +0.360 | 52.7% | +174.7 | -6.10% |
| **指値 −0.75ATR（3日有効）** | 477 | **+0.413** | 53.1% | **+196.8** | -5.91% |
| 指値 −1.00ATR（3日有効） | 452 | +0.404 | 52.9% | +182.3 | -6.18% |

**候補を1銘柄に絞らず、上位10候補すべてに指値を置いて刺さったものを買う**と、
約定率の低下は候補数でカバーされ、取引数はほぼ維持したまま1回あたりの質だけが上がる。

最良は **−0.75ATR / 3営業日有効**。0.5〜1.0ATRの広い範囲で +0.36〜0.42R とプラトーになっており、
特定の値に過剰最適化した結果ではない。

**約定の内訳（−0.75ATR / 3日有効、候補ベース n=1,566）**
- 約定率 56.2%（翌日 64%・2日目 21%・3日目 15%）
- 22.0% はギャップダウンで指値より安く約定（平均 -1.99% お得）
- 未約定銘柄はその後8日で中央 +3.51%、71.6%が上昇 → **強い銘柄を取り逃がすコストは実在する**。
  それでも約定分の質向上が上回るのは、決済が2R利確で頭打ちになるルールだから。

## 5. 効かなかった工夫（重要）

「急騰した銘柄はもっと深い指値にすべき」「過熱銘柄は見送るべき」という直感は、**検証すると成績が悪化した**。

| ルール | 取引数 | 平均R | 勝率 | 年間合計R |
|---|---|---|---|---|
| 一律 −0.75ATR | 309 | **+0.408** | 53.1% | +199.5 |
| 過熱度連動 −0.75〜−1.25ATR | 301 | +0.357 | 52.5% | +170.2 |
| 過熱度連動 ＋ 過熱銘柄は見送り | 268 | +0.296 | 51.9% | +125.7 |

理由は §2 の通り。ATRがすでに過熱度を織り込んでいるので、上乗せは「深すぎる指値」になって
一番伸びる銘柄を取り逃がすだけになる。**ルールは単純なまま（一律0.75ATR）が最良。**

## 6. 頑健性チェック

**期間を前半／後半で分割**（後半は相場環境が悪く全戦略の成績が落ちるが、優劣は不変）

| 戦略 | 前半 平均R | 後半 平均R |
|---|---|---|
| 翌日寄付成行 | +0.265 | +0.092 |
| 指値 −0.75ATR 3日 | +0.591 | +0.219 |

**建玉スロット数を変えた場合の平均R**

| 戦略 | 1銘柄 | 2銘柄 | 3銘柄 | 5銘柄 |
|---|---|---|---|---|
| 翌日寄付成行 | +0.167 | +0.179 | +0.139 | +0.207 |
| 指値 −0.75ATR 3日 | +0.429 | +0.408 | +0.387 | +0.355 |

**高精度シグナル（スコア16以上）に限定**

| 戦略 | 取引数 | 平均R | 勝率 |
|---|---|---|---|
| 翌日寄付成行 | 238 | +0.193 | 47.1% |
| 指値 −0.75ATR 3日 | 191 | +0.458 | 53.4% |
| 指値 −1.00ATR 3日 | 171 | +0.535 | 57.3% |

高精度シグナルは元々ボラが高いので、−1.00ATR まで引いてよい。

**心理面**：「買った当日をプラスで終える確率」は 48.4% → 51.5%（−1.5ATRなら 55.1%）。
劇的には変わらない。**含み損そのものは消えない**（平均含み損 -6.46% → -5.91%）。
変わるのは、含み損が「高値掴みによるもの」ではなくなること、そして勝率が 46%→53% になること。

## 6.5 売り（空売り）は買いと非対称だった

売抽出v13 のシグナルを同じ手順で再現（3,571件）し、同じ検証をかけた。

**翌日高値は当日終値から 中央 +0.39ATR 上まで戻る**（終値超え率 84.0%、P75 +0.70ATR）。
寄付で空売りすると 92.9% が当日一度は含み損（中央 +1.02%）。ここまでは買いの鏡像。

ところが**「戻りを待って高く売る」は成績が落ちた**。

| 戦略 | 年間取引 | 平均R | 勝率 | 年間合計R |
|---|---|---|---|---|
| **翌日寄付で成行売り（現行）** | 500 | **+0.062** | 48.1% | +31.1 |
| 指値売り +0.25ATR（3日有効） | 498 | +0.031 | 49.8% | +15.6 |
| 指値売り +0.50ATR（3日有効） | 489 | +0.010 | 48.5% | +5.0 |
| 指値売り +0.75ATR（3日有効） | 456 | -0.044 | 46.5% | -20.0 |
| 指値売り +1.25ATR（3日有効） | 351 | -0.157 | 40.1% | -55.2 |

下抜けを待つ逆指値売りも、すべての水準でマイナスだった。

| 戦略 | 年間取引 | 平均R | 勝率 |
|---|---|---|---|
| 逆指値売り −0.25ATR（3日有効） | 497 | -0.056 | 45.2% |
| 逆指値売り −0.50ATR（3日有効） | 470 | -0.049 | 44.8% |
| 逆指値売り −1.00ATR（3日有効） | 373 | -0.162 | 38.1% |

**結論：売りは寄付成行のまま。指値も逆指値も入れない。**

ただしこの結論は信頼度が低い。検証期間は **+16.2% の上昇相場1年のみ**で、空売りには構造的に
不利な期間。寄付成行ですら +0.062R（ほぼ損益ゼロ）で、期間を前半／後半に割ると
前半 +0.143R / 後半 −0.019R と安定していない。下落相場のデータが貯まったら再検証が必要。

そのため売抽出v13 には「戻り目安 +0.39ATR」「戻り上限 +0.70ATR」を**参考値として**表示し、
★エントリーは寄付成行と明示している。

## 7. 実行手順

### 導入（1回だけ）

1. VBEを開く（Alt+F11）→ [ファイル] → [ファイルのインポート] → `vba/Mod_推奨指値.bas` を読み込む。
2. `推奨指値ボタン設置` を1回実行（任意。買抽出v13・売抽出v13・個別銘柄にボタンが付く）。

### 毎日

1. データ取込後、`推奨指値_全シート更新` を実行する（ボタンでも可）。4シートすべてに出る。
2. **買い**：候補すべてに **終値 − 0.75 × ATR14**（★本命指値の列）で買い注文を出す。
   3営業日有効（SBI等の「期間指定」注文）。1銘柄に絞らないことが前提。
3. 刺さった銘柄だけ建てる。刺さらなければ追いかけない。取り消して翌日の候補に回す。
4. **売り**：寄付成行のまま。戻りを待たない。
5. 建玉後は現行どおり：損切 = 建値 ∓ 2ATR（3〜10%に制限）、利確 = 損切幅×2、10営業日で時間決済。
   ※ 損切・利確は**約定値基準で引き直す**こと（現行のO列/P列は現在値基準なのでズレる）。
   モジュールの「約定時損切」「約定時利確」列がその値。

### シート別の出力位置（既存の列は一切書き換えない）

| シート | 出力位置 | 内容 |
|---|---|---|
| 買抽出v13 | U〜AC列 | 基準終値／ATR14／第1指値 −0.5ATR／★本命指値 −0.75ATR／深押し −1.25ATR／本命到達率／約定時損切／約定時利確／ひとこと |
| 売抽出v13 | U〜AC列 | 基準終値／ATR14／戻り目安 +0.39ATR／戻り上限 +0.70ATR／★エントリー（寄付成行）／戻り到達率／建値時損切／建値時利確／ひとこと |
| 厳選TOP2 | N〜Q列（買 18〜22行／売 26〜30行） | ATR14／★本命指値（売は★エントリー）／到達率（売は戻り目安）／約定時損切 |
| 個別銘柄 | A24〜C29 | 基準終値／ATR14／買 第1・★本命・深押しの3水準と各到達率 |

- 到達率は**その銘柄自身の直近120営業日の実績**（翌日安値がその水準に届いた割合）。全体統計ではない。
- 基準終値は**終値シートE列（直近の確定終値）**。抽出シートの現在値は抽出時刻のRSS値で
  古いことがあるため使わない（例：8/14の6027は抽出シート3,150円＝8/13終値、実際の終値は3,750円）。
- **高精度シグナル（スコア16以上）は自動で −1.00ATR に切り替わる**（平均+0.535R、勝率57.3%）。
  「ひとこと」列に「高精度→1ATRまで引ける」と出る。

## 8. この分析の限界（正直に）

- **約定の仮定が楽観的**：安値が指値にタッチすれば約定したものとして計算している。
  実際は板の順番で約定しないことがあるため、実効約定率は試算（56%）より低くなる。
- **手数料・スリッページ未計上**：片道0.05%×2 ≒ 0.1%。損切幅3〜10%に対して 0.01〜0.03R 程度の目減り。
- **検証期間は1年（250営業日）のみ**。この期間の市場は +16.2%（300銘柄の中央値ベース）の上昇相場で、
  年率ボラティリティ 18.9%。下落相場での挙動は検証できていない。
- **TOPIX行のデータに断層**があった（終値シート5行目が直近2日だけ4,197、それ以前は896前後）。
  市場全体の指標は300銘柄の日次リターン中央値で代用した。**この行は要修正**。
- 売買代金・流動性の制約、板の厚みは考慮していない。
- 過去の統計であり、将来の値動きを保証するものではない。

```
analysis/extract.py    → xlsm から OHLCV を抽出（raw.pkl）
analysis/build.py      → 300銘柄×250日の行列に整形（data.npz）
analysis/indicators.py → EMA/RSI/MACD/ATR/ADX/VWAP
analysis/signal.py     → Mod_買抽出v13 のスコアを再現（feat.npz）
analysis/analyze1.py   → シグナル翌日の値動き統計
analysis/analyze3.py   → 支持線の到達率・下落要因の分解
analysis/kmodel.py     → 下落幅のATR倍数モデル
analysis/sim.py        → 指値深さの単体検証
analysis/portfolio.py  → 運用シミュレーション
analysis/robust.py     → 期間・スロット数・シグナル強度での頑健性
analysis/adaptive.py   → 過熱度連動ルールの検証（不採用）
analysis/final_stats.py→ 最終比較
analysis/cand_price.py → 当日候補の指値算出
analysis/sell_signal.py → Mod_SellExtrac の売りスコアを再現
analysis/sell_sim.py    → 指値売り（戻り待ち）の検証
analysis/sell_break.py  → 逆指値売り（下抜け確認）の検証
analysis/verify_vba.py  → VBAモジュールと同一ロジックで4シートの出力を再現・検証
analysis/results_2026-08-14.txt   → 買い側の全出力ログ
analysis/results_売り_4シート.txt → 売り側とシート配置検証の全出力ログ
```
