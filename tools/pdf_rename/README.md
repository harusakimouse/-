# PDF 自動リネーム（`rename_pdfs.py`）

フォルダ内の **PDF だけ** を、中身を読んで分かりやすいファイル名に付け替えます。
Excel・画像・テキストなど **PDF 以外のファイルには一切触れません**。

付ける名前の形：`書類の種類_相手先や物件名_日付.pdf`

```
scan_0001.pdf → 総会議事録_グランドヒルズ青山マンション_2025-06-15.pdf
img_2024.pdf  → 御請求書_株式会社サンプル管理サービス_2026-08-10.pdf
無題.pdf      → 重要事項説明書_パークレジデンス_2026-03-01.pdf
```

## 1. 準備（Windows）

1. Python をインストール（未導入なら Microsoft Store の「Python 3」でOK）
2. コマンドプロンプトで:

   ```
   pip install pymupdf
   ```

3. **スキャンした画像PDF**（文字データが入っていないPDF）を読むには、追加で:

   ```
   pip install pytesseract pillow
   ```

   さらに Tesseract 本体が必要です。
   <https://github.com/UB-Mannheim/tesseract/wiki> からインストーラを入手し、
   インストール中の「Additional language data」で **Japanese** にチェックを入れてください。

## 2. 使い方

まずは**ドライラン**（実際には変えず、変更案だけ表示）：

```
python rename_pdfs.py "C:\Users\Abe Hideaki\...\スキャン　マンション"
```

問題なさそうなら `--apply` を付けて実行：

```
python rename_pdfs.py "C:\Users\Abe Hideaki\...\スキャン　マンション" --apply
```

| オプション | 意味 |
| --- | --- |
| （なし） | ドライラン。変更案を表示するだけ |
| `--apply` | 実際にリネームする |
| `--recursive` | サブフォルダの PDF も対象にする |
| `--undo` | 直前のリネームをすべて元に戻す |
| `--no-ocr` | スキャンPDFの OCR を使わない（速い） |
| `--lang jpn` | OCR の言語を変える（既定 `jpn+eng`） |

## 3. 元に戻す

`--apply` で実行すると、対象フォルダに `.pdf_rename_log.csv`（変更履歴）が残ります。

```
python rename_pdfs.py "対象フォルダ" --undo
```

で元のファイル名に戻せます。

## 4. 判定のしくみ

1. 1〜2ページ目の文字を取り出す（PyMuPDF → pdfminer → pypdf の順に試行）
2. 文字が入っていなければ、ページを画像化して OCR
3. 取り出した文字から次を拾う
   - **書類の種類**：請求書・見積書・領収書・契約書・総会議事録・管理規約・重要事項説明書 など
   - **相手先／物件名**：`〇〇マンション`『〇〇レジデンス』などの建物名、なければ `株式会社〇〇` などの社名
   - **日付**：`2026年8月10日` / `2026/08/10` / `令和7年6月15日` を `2026-08-10` 形式に統一
4. 何も見つからないPDFは **リネームせずスキップ**（勝手に変な名前は付けません）
5. 同じ名前になる場合は末尾に `_2`, `_3` を付けて重複を回避

書類の種類を増やしたいときは、スクリプト内の `DOC_TYPES` に単語を足してください。
