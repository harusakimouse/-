# V805のVBA：取込日数を250日にしたもの

元のコードから**数字だけ**を変えています。処理の中身は一切変えていません。

E列が最新日なので、250日 → 最終列 = 5 + 250 - 1 = **254 = IT列**。

## 入れ方

### .bas の4本

1. `Alt + F11` でVBAエディタ
2. 左のツリーで**同じ名前の既存モジュールを右クリック →「解放」→「いいえ」**
   （先に消さないと `Module71` のように重複します）
3. **ファイル → ファイルのインポート** で `.bas` を選ぶ
4. 4本ぶん繰り返す
5. **デバッグ → VBAProject のコンパイル** でエラーが出ないことを確認

### Sheet10 だけは手作業です

シートモジュールはインポートできません。

1. VBAエディタで `Sheet10` をダブルクリック
2. `Ctrl + A` → `Delete`
3. `Sheet10_本文.txt` の中身を全部貼り付け

面倒なら、`For c = 5 To 104` の **104 を 254 に直すだけ**でも同じです（1箇所）。

## データ取込シートの設定

```
K1 = 取得本数      M1 = 開始日
```

`M1` は**開始日**で、そこから**未来方向へ**本数ぶん返ります。
250営業日ほしいときは

- `M1` = 今日から **420日ほど前**の日付（`yyyymmdd` 形式）
- `K1` = **400**

420暦日 ≒ 282営業日なので、250日を確実に含みます。

## まだ変えていないもの（抽出系）

| モジュール | 現在 |
|---|---|
| `Mod_売抽出_下降VWAP` | `HIST_DAYS = 60` / `HIST_LAST_COL = 64` |
| `Mod_買抽出_順張りVWAP` | `HIST_DAYS = 60` / `HIST_LAST_COL = 64` |
| `Mod_買抽出v13` | `104` が6箇所 |
| `Mod_SellExtrac` | `104` が1箇所 |

`HIST_DAYS` は読み込む配列の長さです。RSI14・MACDのような**固定窓の指標は影響を
受けません**が、「履歴全体の高値／安値」のように期間を区切らない使い方があると、
60日高値が250日高値に変わって**意味が変わります**。

取込側で250日入るのを確認してから、中身を見て判断するのが安全です。
