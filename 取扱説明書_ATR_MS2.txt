------------------------------------------------------------------------
0. 概要
------------------------------------------------------------------------
・監視銘柄（最大350）の株価から ATR を求め、寄り方向・出来高・トレンド・
　ボラティリティ・時間帯などの条件でエントリー可否を自動判定し、
　Entry / SL（損切り）/ TP1〜TP3（利確）の価格を自動計算するブックです。
・DATA_MS2 の B〜I 列に株価が入ると、J〜Y 列が数式で自動計算されます
　（マクロを動かさなくても動作します）。
・RssMarket 関数（要MARKETSPEED II起動）を使えば株価もリアルタイム取得可能。
・トレード結果の記録（TRADE_MS2）と銘柄別成績集計（RANK_MS2）はマクロで出力。

1. シート構成
------------------------------------------------------------------------
① 使い方        … 簡易マニュアル（本書の要約）
② StockList_MS2 … 監視銘柄リスト。A=銘柄コード, B=銘柄名（手入力／最大350）
③ DATA_MS2      … メイン表（ATR・判定・Entry/SL/TP）。本書2章参照
④ TRADE_MS2     … 抽出トレードと結果ログ（マクロ出力）
⑤ RANK_MS2      … 銘柄別の成績ランキング（マクロ集計）
（＋ 操作パネル_MS2 … MS2_Build_Menu 実行で作成される操作ボタン専用シート）

DATA_MS2 のレイアウト：
　1行目 … 色付きの空白帯（タイトル記入用）
　2行目 … 見出し
　3行目以降 … データ（3〜352行 ＝ 350銘柄）
　A列 … 株探リンク（クリックで kabutan.jp の銘柄ページを開く）


------------------------------------------------------------------------
2. DATA_MS2 列定義（A〜AB／全28列）
------------------------------------------------------------------------
 列  見出し           区分   内容 / 計算
 --  ---------------  -----  ------------------------------------------
 A   No               数式   連番（=ROW()-2）
 B   株探リンク       数式   クリックで株探ページ（表示は「株探」）
 C   銘柄コード       数式   StockList_MS2 のA列から連動
 D   銘柄名           数式   StockList_MS2 のB列から連動
 E   現在値           入力   RssMarket("コード","現在値") または手入力
 F   高値             入力   当日高値
 G   安値             入力   当日安値
 H   終値             入力   終値（現値系）
 I   出来高           入力   出来高
 J   前日高値         入力
 K   前日安値         入力
 L   前日終値         入力
 M   寄り方向         数式   E>L なら BUY-DAY、そうでなければ SELL-DAY
 N   ATR(14・5分足)   数式   当足のTrue Range（下記3章）／マクロでは14期間ATR
 O   ゾーン(出来高)   数式   出来高フィルタ：VOL-OK / VOL-NG
 P   STOP-BUY         数式   E>J なら ON（前日高値ブレイク）
 Q   STOP-SELL        数式   E<K なら ON（前日安値ブレイク）
 R   売買種別         数式   BUY / SELL / （空＝見送り）
 S   Entry            数式   エントリー価格（＝現在値E）
 T   SL               数式   損切り価格
 U   TP1              数式   利確1
 V   TP2              数式   利確2
 W   TP3              数式   利確3
 X   2回目戻し        数式   2ND / 1ST（押し戻り判定）
 Y   時間帯           数式   寄り付き / 後場 / 引け前 / その他（現在時刻基準）
 Z   ボラフィルタ     数式   VOL-HIGH / VOL-NORMAL
 AA  ダマシ除去       数式   OK / NG（ダマシフィルタ）
 AB  トレンド方向     数式   UP / DOWN / FLAT

 入力列は E〜L。色の意味：青字＝手入力/RSS入力セル、黒字＝自動計算セル。
 ※4〜5章の入口/出口条件は列記号が上記に対応（現在値=E、ATR=N など）。


------------------------------------------------------------------------
3. ATR（K列）の仕様
------------------------------------------------------------------------
True Range（当足）：
　TR = MAX( 高値-安値 , |高値-前日終値| , |安値-前日終値| )

・数式版（K列）：上記 TR をそのまま表示します。
　1行＝1銘柄のスナップショット構造のため、K列は「当足のTR」です。
・厳密な14期間ATR（5分足）：14本ぶんの5分足時系列が必要です。
　これは『ATR更新_MS2（MS2_Calc_ATR_5min_14）』マクロ側で、
　TRを14本ぶん平均して算出する設計です。
　（注：マクロのTRバッファは呼び出しごとに初期化されるため、
　　連続運用では別途バッファ保持の作り込みが必要です＝既知の制約）


------------------------------------------------------------------------
4. 入口条件（エントリー条件）  ※O列の判定
------------------------------------------------------------------------
まず各フィルタを評価します（B〜Iが入力済みで、K=ATR>0 が前提）。

 ● 寄り方向 J
     BUY-DAY  … 現在値 B ＞ 前日終値 I
     SELL-DAY … 上記以外

 ● 出来高ゾーン L
     VOL-OK … 出来高 F ＞ 0 かつ F ＞ (F/3)×2.5
     VOL-NG … 上記以外
     ※仕様上、F>0 であれば実質 VOL-OK になります（既知のクセ）。

 ● 前日レンジ抜け
     STOP-BUY  M = ON … 現在値 B ＞ 前日高値 G
     STOP-SELL N = ON … 現在値 B ＜ 前日安値 H

 ● トレンド方向 Y
     UP   … 高値C＞前日高値G かつ 安値D＞前日安値H
     DOWN … 高値C＜前日高値G かつ 安値D＜前日安値H
     FLAT … 上記以外

 ● ボラフィルタ W
     VOL-HIGH   … ATR K ＞ 現在値 B × 5%
     VOL-NORMAL … 上記以外

 ● 2回目戻し U
     2ND … 現在値B＞終値E かつ |現在値B-終値E| ＜ ATR×0.5
     1ST … 上記以外

 ● ダマシ除去 X
     OK … L=VOL-OK かつ W=VOL-NORMAL かつ U=2ND
     NG … 上記以外

── 最終エントリー判定 O ─────────────────────────────
 BUY 成立：
     J=BUY-DAY  かつ L=VOL-OK かつ N(STOP-SELL)=ON
     かつ X=OK  かつ Y≠DOWN
 SELL 成立：
     J=SELL-DAY かつ L=VOL-OK かつ M(STOP-BUY)=ON
     かつ X=OK  かつ Y≠UP
 いずれも満たさない場合は「見送り（空欄）」。

 ※重要（既知のクセ）：BUY は「BUY-DAY(現在値＞前日終値)」でありながら
 　「STOP-SELL=ON(現在値＜前日安値)」を要求します。両立には
 　前日安値＞前日終値 が必要で通常は成立しにくく、サインは
 　出にくい設計です（提供元マクロの条件をそのまま踏襲）。
 　条件を緩めたい場合はカスタマイズで対応できます。


------------------------------------------------------------------------
5. 出口条件（Entry / SL / TP）
------------------------------------------------------------------------
エントリー価格 P ＝ 現在値 B。ATR（K）を基準に以下を自動計算します。

 【BUY の場合】
     SL  Q = Entry − ATR×1.5
     TP1 R = Entry + ATR×1.5      （リスクリワード 1 : 1）
     TP2 S = Entry + ATR×2.0      （        〃      1 : 1.33）
     TP3 T = Entry + ATR×3.0      （        〃      1 : 2）

 【SELL の場合】
     SL  Q = Entry + ATR×1.5
     TP1 R = Entry − ATR×1.5
     TP2 S = Entry − ATR×2.0
     TP3 T = Entry − ATR×3.0

 ・損切り幅は常に 1.5ATR。利確は 1.5 / 2.0 / 3.0 ATR の3段階。
 ・分割決済（TP1で一部利確→建値SL→TP2/TP3で残り）を想定した設計です。

 【結果判定（TRADE_MS2／MS2_Eval_Trades）】
 　BUY : TP1到達→"TP1"(損益=TP1-Entry) / SL到達→"SL"(損益=SL-Entry)
 　　　　いずれでもない→"END"(引け決済扱い)
 　SELL: 上記の売り版
 　※現行の判定は簡易版で、当日の実際の高値/安値を参照していません
 　　（構造上ほぼTP1判定になります）。実運用の勝敗集計には、
 　　ザラ場のH/L到達判定を追加する作り込みが必要です＝既知の制約。


------------------------------------------------------------------------
6. 時間帯（V列）の区分
------------------------------------------------------------------------
 現在時刻（PCの時計）を基準に区分します。
     09:00〜09:30 … 寄り付き
     12:30〜14:30 … 後場
     14:30〜15:00 … 引け前
     上記以外     … その他


------------------------------------------------------------------------
7. RANK_MS2（成績集計）の指標
------------------------------------------------------------------------
 TRADE_MS2 を銘柄コード別に集計します（MS2_Update_Ranking）。
 列構成（A=株探リンク / D=銘柄名 を追加、RR以降は1列右へ移動）：
     A 銘柄コード（株探）… クリックで株探ページを開く
     B 勝率     … 勝ちトレード数 ÷ (勝ち＋負け)
     C PF       … 総利益 ÷ 総損失（プロフィットファクター）
     D 銘柄名   … StockList_MS2 から自動取得
     E RR       … 総利益 ÷ 勝ち数（平均利益）
     F 最大DD   … 1トレード最大損失額
     G 平均RR   … 総利益 ÷ 勝ち数（RRと同値）
     H 連勝 / I 連敗 … 直近の連続勝ち／負け数
     J 月次損益 … 当月の損益合計
     K トレード数… 総件数
 ※見出し（1行目）は MS2_Update_Ranking 実行時に自動で書き直されます。

------------------------------------------------------------------------
9. 使い方（推奨フロー）
------------------------------------------------------------------------
 ■ 数式だけで使う（マクロ不要・350銘柄対応）
   1) StockList_MS2 に銘柄コード（4桁）と銘柄名を入力
   2) DATA_MS2 の B〜I に株価を入力（手入力 or RssMarket）
   3) J〜Y（ATR・判定・Entry/SL/TP）が自動計算される
   4) A列の株探リンクから個別銘柄の詳細を確認

 ■ ボタンで使う
   1) Excelで開く → Alt+F11（VBE）
   2) 重複モジュール Module2 を削除（「あいまいな名前」エラー回避）
   3) MS2_Menu.bas をインポート
   4) Alt+F8 →『MS2_Build_Menu』を実行 →「操作パネル_MS2」にボタン生成
   5) 以後はボタンから操作（RssMarket利用時はMARKETSPEED IIを起動）


------------------------------------------------------------------------
10. 既知の注意点・仕様上のクセ
------------------------------------------------------------------------
 (1) 『MS2_Init_Book』は実行しないこと。全シートを初期化し、組み込んだ
     数式（350銘柄ぶんのATR計算）が消えます。ボタン作成は表を壊さない
     『MS2_Build_Menu』を使用してください。
 (2) Module1 と Module2 に MS2_Init_Book / MS2_Create_Buttons が重複定義
     されており、そのままではマクロがコンパイルエラーになります。
     VBEで Module2 を削除してください。
 (3) 『銘柄反映_MS2』ボタンは先頭50銘柄のみコピー（VBA仕様）。350銘柄は
     A列の数式連動（自動）で対応済みなので、このボタンは使わない運用推奨。
 (4) K列ATRは当足TR。厳密な14期間ATR(5分足)はマクロ側で算出（3章参照）。
 (5) 出来高ゾーン(L)は F>0 で実質 VOL-OK になる簡易判定（4章参照）。
 (6) BUYの入口条件は成立しにくい設計（4章の「重要」参照）。
 (7) 結果判定(MS2_Eval_Trades)は簡易版でザラ場H/L未参照（5章参照）。
 (8) RssMarket は楽天 MARKETSPEED II の起動が必要。未起動時はB〜I手入力。

 これらの条件緩和・ATRの厳密化・結果判定の高度化などのカスタマイズは
 対応可能です。ご要望をお知らせください。

========================================================================
 追補（2026-08-01）: MS2_Core.bas 導入 と ATR(14) の正式化
========================================================================
整形により DATA_MS2 は「見出し=2行目 / データ=3行目〜」に変わりました。
旧マクロは `For i = 2 To lastRow`（＝見出し行から処理）だったため、
行ズレ・型不一致エラーの原因になります。これを修正し、ATRを銘柄別の
正しい14期間ATRにした一式が MS2_Core.bas です。

■ 導入手順
  1) Excelで開く → Alt+F11（VBE）
  2) 旧 Module1 と 重複 Module2 を「解放（削除）」
  3) ファイル → ファイルのインポート → MS2_Core.bas
  4) ボタンは MS2_Menu.bas → MS2_Build_Menu で作成
  ※MS2_Core と MS2_Menu の2モジュール構成になります。

■ 主な変更点
  ・DATA_MS2 を処理するループは全て 3行目開始（DATA_FIRST=3）。
  ・MS2_Update_StockList_To_DATA は「A列の株探リンクを350銘柄ぶん
    再設定」する処理に変更（旧50銘柄上限を撤廃／リンク復旧用）。
  ・MS2_Auto_All から銘柄反映呼び出しを削除（A列は数式連動のため）。
  ・MS2_Reset_ATR_History を追加（ATR蓄積のやり直し用）。

■ ATR(14) の正式仕様（銘柄別・Wilder平滑）
  隠しシート ATRHIST_MS2（A:コード / B:サンプル数 / C:TR累計 / D:ATR）に
  銘柄コード別で TR を蓄積します。ATR更新を実行するたびに：
    ・最初の14回 : TRの単純平均（シード）  ATR = ΣTR ÷ 回数
    ・15回目以降 : Wilder平滑            ATR = (前ATR×13 + TR) ÷ 14
  として、同一銘柄の正しい14期間ATRへ収束します。
  TR = MAX(高値-安値, |高値-前日終値|, |安値-前日終値|)

■ 運用上の注意
  ・ATR更新は「5分足が確定するタイミングで1回」を目安に実行してください
    （短時間に何度も回すと同じ足を多重カウントします）。
  ・TRは RSS の 高値/安値/前日終値 ベースです。純粋な5分足OHLCが必要な
    場合は、5分足データの取得元を別途用意する拡張が必要です。
  ・蓄積をやり直したいときは MS2_Reset_ATR_History を実行。
  ・ATRHIST_MS2 は既定で非表示。確認したい場合はシートの再表示で見えます。

========================================================================
 追補: 前日高値・前日安値の取得（RSS非対応の代替）
========================================================================
RssMarket では「前日高値」「前日安値」が取得できない環境向けに、
当日の高値・安値を引け後に保存し、翌営業日に「前日値」として使う方式を
用意しました（隠しシート PREVDAY_MS2 に銘柄別で蓄積）。

■ マクロ
  MS2_Save_PrevDay … DATA_MS2 の当日 高値(F)/安値(G) を PREVDAY_MS2 に保存
                     （※15:00の大引け後、RSS接続中に1回実行）
  MS2_Load_PrevDay … PREVDAY_MS2 の値を DATA_MS2 の J:前日高値 / K:前日安値 に反映
  ・RSS式セットは J/K を触りません（RSS非対応のため消去）。
  ・全自動_MS2 は RSSセット後に MS2_Load_PrevDay を自動実行します。

■ 毎日の運用
  1) 寄り前〜場中：全自動_MS2（またはRSS式セット→前日値反映→…）
     → J/K に「前日（前営業日）の高安」が入り、STOP/トレンド判定が有効化
  2) 大引け後（15:00〜）：前日値保存_MS2 を1回
     → 本日の高安が保存され、翌営業日の前日値になる
  ※初日は前日値が無いため J/K は空（=0扱い）。2日目以降に有効。

■ 注意
  ・MS2_Save_PrevDay は必ず「当日の高安が確定した引け後」に実行してください
    （場中に実行すると、その時点までの高安が保存されます）。
  ・PREVDAY_MS2 は既定で非表示。中身を見たい場合は再表示してください。
