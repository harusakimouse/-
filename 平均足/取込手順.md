# マクロの取り込み方（10秒・3ステップ）

アップロードされたブックには**マクロの入れ物（VBAプロジェクト）が入っていません**。
外から無理に埋め込むとブックが壊れる可能性があるため、標準の取り込み方で入れてください。

## 手順
1. ブックを開く → **Alt + F11**（VBEが開く）
2. メニュー **ファイル → ファイルのインポート**
3. **`Mod_HeikinAshi_ShiftJIS.bas`** を選ぶ → 完了

※ 文字化けするのは UTF-8 版です。**必ず `_ShiftJIS` の方**を取り込んでください。

## 実行
- **Alt + F8** → `平均足_買い抽出` → 実行
- 「平均足」シートが自動で作られ、点数順に候補が並びます
- 売り（空売り・手仕舞い判定）は `平均足_売り抽出`

## 実行するタイミング
**引け後 15:30 以降**。当日出来高が確定していないと候補が出ません。
ザラ場中に回したい時は、モジュール先頭の
`Public Const HA_SKIP As Long = 0` を `1` に変えると前日の足で判定します。

## 最初に見直す設定（モジュール先頭）
| 定数 | 初期値 | 意味 |
|---|---|---|
| `HA_CAPITAL` | 3000000 | 運用資金（円）|
| `HA_RISK` | 0.01 | 1回で失ってよい割合 |
| `HA_PASS` | 4 | 合格点。下げると候補が増える |
| `HA_VOLRATE` | 1.6 | 出来高倍率。**下げると成績が落ちる** |
| `HA_RR` | 2 | 利確1の倍率 |

## 保存
必ず **「Excel マクロ有効ブック (*.xlsm)」** で保存してください。

## 売買ルールをシートに出す
**Alt + F8 → `平均足_ルール表示`**
このブックの中に「平均足ルール」シートが作られ、買う条件・点数・出口・資金管理・検証結果が
1枚にまとまって出ます。MDファイルはもう不要です。

# OHLCVデータの自動取込（追加分）

## 前提
このブックを、**`OHLCV　明日売買　ボリンジャー送信.xlsm` と同じフォルダー（デスクトップ）に保存**してください。

## 取り込むモジュール
`Mod_HeikinAshi_Auto_ShiftJIS.bas` を、本体と同じ手順（Alt+F11 →ファイル→ファイルのインポート）で追加。

## マクロ
| マクロ名 | 中身 |
|---|---|
| `平均足_取込して抽出` | 今すぐ取り込んで候補を出す（手動）|
| `平均足_自動開始` | 毎日 15:35 に 取込→抽出 を自動実行 |
| `平均足_自動停止` | 自動をやめる |
| `平均足_データ取込` | 取り込みだけ |

## ブックを開いた時に自動でセットしたい場合
Alt+F11 → 左の「ThisWorkbook」をダブルクリック → 下の3行を貼る

    Private Sub Workbook_Open()
        平均足_自動開始_起動時
    End Sub

## 安全面
- 元ブックは **読み取り専用** で開き、**保存しません**（1セルも書き換えません）
- 元ブックのマクロは **動かさない設定** で開きます
- すでに開いている場合は、そのまま読むだけで閉じません

## 注意
`Application.OnTime` はExcelが起動していないと動きません。
**15:35 の時点でExcelとこのブックを開いたまま**にしてください。
