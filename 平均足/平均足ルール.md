# 平均足トレード　完成ルール（日本株・日足）

## 結論
- **平均足は「トレンドの終わり＝反転」を取る道具**。エントリーは反転が形になった2〜5本目だけ。
- 実データ（300銘柄×250日）で検証した結果、**勝率49.2%／1回あたり平均 +0.40R**（手数料往復0.3%込み）。
- 同時5銘柄・1回1%リスクで運用すると **250日で +102.8%、最大下落 13.2%**（同時3銘柄なら +67.4%／下落7.4%）。
- 100%勝てる方法ではない。**負けを1%で切ることが利益の源泉**。

---

## 1. 買う条件（9つ全部そろった時だけ）

| # | 条件 | 理由 |
|---|------|------|
| 1 | 当日出来高 ≧ 5日平均 × **1.6倍** | これが一番効く。1.2倍では +0.20R、1.6倍で +0.43R |
| 2 | 平均足の陽線が **2〜5本連続** | 6本目以降は高値づかみ |
| 3 | その前に陰線が **3本以上**（20日線の上なら2本以上） | 下げの終わりを取る |
| 4 | 最新の平均足に **下ヒゲが無い** | 買い方が完全に優勢な形 |
| 5 | 直近3日の安値 > その前4〜8日の安値（**安値切り上げ**） | 底が固まった証拠 |
| 6 | 終値 > **20日線** | 逆行しているものは買わない |
| 7 | **25日線からの乖離 ≧ 0%** | 下げ続けている株の逆張りは負ける（検証で確認） |
| 8 | **RSI(14) ≧ 50** | 50割れは +0.04R、50超で +0.21R |
| 9 | 平均足の実体率 ≦ 0.85 | 行き過ぎた足は翌日戻される |

さらに 株価300円以上・5日平均出来高20万株以上（板が薄い株は入れない）。

## 2. 点数（順位を決める＝ここが利益に直結）
候補が複数出た日は **点数の高い順に採用**する。早い者順にすると年+34%、点数順なら年+103%。

| 加点 | 内容 |
|---|---|
| +3 | 転換直前が**十字線**（実体率0.35以下） |
| +2 | 出来高2倍以上（1.6倍以上なら+1） |
| +2 | RSI 65以下（適温）／ RSI75以上は −1 |
| +2 | 転換前の陰線が3〜5本 |
| +1 | 9日線 > 18日線／その直近ゴールデンクロス |
| +1 | 20日安値から1.5%以内の反発（支持線） |
| +1 | 20日高値を終値で更新（ブレイク） |
| +1 | ストキャス %K が20を上抜け |
| +1 | RSIが50を上抜けた当日 |
| +1 | ATR ≦ 株価の3.5%（値動きが素直） |
| +1 | 実体率 0.3〜0.7 |

**合格点＝4点以上**。

## 3. 出口（ここを守らないと必ず負ける）

1. **損切**＝ min(平均足の安値, 直近3日安値) − ATR14 × 0.5。ただし最大 −6%。
   買った直後に逆指値を入れる。**入れた後は絶対に下げない**。
2. **利確1**＝ 損切幅の**2倍**（+2R）に届いたら**半分売る**。同時に残りの損切を買値まで上げる。
3. **全部手仕舞い**＝ 平均足が**陰線2本連続**になった時。→ これが平均足の本番。
4. **時間切れ**＝ 5営業日たっても +2R に届かない玉は、勝ち負けに関係なく手仕舞う。

検証で試した出口の比較（平均R）
- 陰線2本で手仕舞い … **+0.43R**（採用）
- 陰線1本で手仕舞い … +0.15R（早すぎる）
- 時間切れ無し … +0.46R（ただし資金が寝る）

## 4. 資金管理
- 1回のリスク＝資金の **1%**。株数 ＝ (資金 × 1%) ÷ (エントリー − 損切) を100株単位に切り捨て。
- 1銘柄に使う金額は資金の25%まで。同時保有は **5銘柄**まで（3銘柄なら下落がさらに小さい）。
- **3連敗したら株数を半分**。月間損失が資金の6%に達したらその月は休む。

## 5. 期待値の計算
- 勝率 49.2%、勝ち平均 +1.9R、負け平均 −1.0R → 1回あたり **+0.40R**
- 1回1%リスクなら 1回あたり **+0.40%**。年150回で理論値 +60%（複利で+100%前後）
- プロフィットファクター 2.15

## 6. 注意（正直に）
- 検証は**直近1年・300銘柄**。相場つきが変われば成績は落ちる。
- 出来高1.6倍が命なので、**引け後（15:30以降）に実行**すること。ザラ場中に回すと出来高が足りず候補が出ない（その時は `HA_SKIP = 1` にして前日で判定する）。
- 寄り成りで買う前提。ギャップアップで始まったら、損切幅が6%を超える場合は見送る。
