# 計算モード復帰パッチ（手動計算のまま固まるのを防ぐ）

RTD（＝RSS の実体）は**再計算が走らないと画面に反映されません**。
計算モードが「手動」のまま放置されると、MarketSpeed II が値を送っていても C 列は固まったままになります。これが「RSS取得しない」の再現性の高い原因のひとつです。

V805 には **エラーハンドラを持たないまま `Application.Calculation = xlCalculationManual` にするプロシージャが 9 個** あります。実行中に一度でもエラーが出ると、手動計算のまま復帰しません。

## 対象一覧

| モジュール | プロシージャ | olevba 出力の行 |
|---|---|---|
| Mod_MS_TimeSeriesImport | `マーケットスピード過去データ取込` | 632 |
| 日付ヘッダー整合 | `日付ヘッダー一括整合` | 857 |
| Mod_SellExtrac | `S_抽出実行` | 4480 |
| Mod_SellExtrac | `S_抽出実行_RSS` | 4921 |
| Mod_売抽出_下降VWAP | `抽出実行_下降` | 5860 |
| Mod_買抽出_順張りVWAP | `抽出実行_順張り` | 6853 |
| **Mod_買抽出v13** | **`抽出実行`** | **7997** |
| Module7 | `修復_ALL` | 8878 |
| Module8 | `古い履歴を消去` | 9334 |
| Module9 | `TrimCore` | 9608 |

とくに `Mod_買抽出v13.抽出実行` は日常的に押すボタンです。ここで落ちると、以降 RSS が一切更新されなくなります。

---

## パッチの当て方（各プロシージャ共通）

### Before

```vba
Private Sub 抽出実行(ByVal minScore As Long, ...)
    ...
    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationManual
    ...
    ' 本体
    ...
    Application.Calculation = xlCalculationAutomatic
    Application.ScreenUpdating = True
End Sub
```

### After

```vba
Private Sub 抽出実行(ByVal minScore As Long, ...)
    ...
    On Error GoTo Cleanup            '★ 追加

    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationManual
    ...
    ' 本体
    ...

Cleanup:                             '★ 追加
    Dim eN As Long, eD As String     '★ 追加
    eN = Err.Number: eD = Err.Description

    On Error Resume Next
    Application.Calculation = xlCalculationAutomatic   '★ 必ず戻す
    Application.ScreenUpdating = True
    Application.EnableEvents = True
    Application.CutCopyMode = False
    Application.StatusBar = False
    On Error GoTo 0

    If eN <> 0 Then
        MsgBox "処理中にエラーが発生しました。" & vbCrLf & _
               eN & ": " & eD & vbCrLf & vbCrLf & _
               "計算モードは自動に戻しました。", vbExclamation
    End If
End Sub
```

ポイントは 3 つだけです。

1. `Application.Calculation = xlCalculationManual` の**前**に `On Error GoTo Cleanup` を置く
2. 正常終了もエラーも **同じ `Cleanup:` を通る**ようにする（正常ルートは `Cleanup` の直前で終わるので `GoTo` は不要、そのまま落ちてくる）
3. `Cleanup:` の中では `On Error Resume Next` にして、復帰処理自体で落ちないようにする

---

## 応急処置（今すぐ直したいとき）

VBE のイミディエイトウィンドウ（Ctrl+G）で:

```vba
Application.Calculation = xlCalculationAutomatic
Application.RTD.ThrottleInterval = 2000
Application.EnableEvents = True
Application.ScreenUpdating = True
Application.CalculateFullRebuild
```

または `03_Mod_RSS環境診断.bas` の **`RSS応急復帰`** を実行してください（同じことをやります）。

---

## 補足: RTD スロットル間隔

`Application.RTD.ThrottleInterval` が `-1` になっていると、
RTD は**手動更新のときしか値を流しません**。既定は 2000（ms）です。

計算モードが自動なのに RSS が更新されない場合は、ここを疑ってください。
`RSS環境診断` マクロの `[C]` セクションに表示されます。
